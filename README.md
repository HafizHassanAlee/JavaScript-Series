## 🛠️ Projects & Practical Applications

I believe programming becomes clearer when concepts are applied to practical problems. These projects are developed alongside my daily learning.

### 0.5. 📦 Inventory Analyzer — Day 10

A small product inventory analysis exercise using an array of product objects. It demonstrates how JavaScript array methods can search, filter, transform, and check product data.

**Features implemented:**
- Find a product by its ID using `find()`.
- Get products that have stock available using `filter()`.
- Create a new array containing product names using `map()`.
- Check whether any product is out of stock using `some()`.
- Check whether every product costs more than 1,000 using `every()`.

**Concepts practised:** Arrays of objects, callback functions, arrow functions, conditions, and the `find()`, `filter()`, `map()`, `some()`, and `every()` array methods.

**Source:** [inventory-analyzer.js](day10.js/inventory-analyzer.js)

### 0.6. 🧪 Array Methods Exercises — Day 11

A focused practice file to strengthen understanding of JavaScript array methods using product data.

**Exercises completed:**
- Find the product whose ID is 3.
- Create a new array containing product names.
- Check whether at least one product costs less than 2,000.
- Check whether every product costs more than 1,000.
- Filter products costing more than 2,000 and then map the result to product names.

**Concepts practised:** Callback parameters, arrow functions, return values, boolean results, `find()`, `some()`, `every()`, `filter()`, `map()`, and method chaining.

**Source:** [array-methods.js](day11.js/array-methods.js)

### 0. 🧑‍🎓 Student Records Management System — Day 08

A menu-driven student record manager built with an array of student objects. It brings together arrays and objects in a practical console application.

**Features implemented:**
- Add a student with a name, roll number, marks and department.
- Display all student records.
- Search for a student by name or roll number.
- Update a student's marks.
- Delete a student record.
- Calculate the class average.
- Check a student's pass/fail status.
- Find and display the student with the highest marks.
- Navigate the features through a repeating menu.

**Concepts practised:** Arrays of objects, object properties, array indexing, `push()`, `splice()`, `for` loops, functions, `switch`, `if/else`, `Number()`, `prompt()` and template literals.

**Source files:**
- [arrays-of-objects.js](day8.js/arrays-of-objects.js)
- [Student-Management-System.js](day8.js/Student-Management-System.js)

**Current learning note:** This is a learning project and can be improved further with stronger input validation, duplicate roll-number checks, and additional empty-list handling.
### 1. 🎓 Student Profile Manager — Day 07

A console-based student profile management project built with JavaScript objects. It displays student information, explores object keys and values, and updates the profile.

**Features:**
- Store student details such as name, age, roll number, department, semester and city.
- Display the profile using `Object.entries()`.
- Retrieve property names with `Object.keys()`.
- Retrieve property values with `Object.values()`.
- Add an email property and update the student's age.
- Delete the city property.
- Display the final updated profile.

**Concepts practised:** Objects, `Object.keys()`, `Object.values()`, `Object.entries()`, property addition, property updates, `delete`, loops, array indexing and template literals.

**Source files:**
- [object-methods.js](day7.js/object-methods.js)
- [FSP-student-profile-manager.js](day7.js/FSP-student-profile-manager.js)
